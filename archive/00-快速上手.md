# 00 · 快速通道（最小动作清单）

> 这是**给已经懂个大概的人**的速查：从空目录到能玩，只有这些动作。
> 想被讲明白（为什么这样做、每步机制是什么）→ 去教程 **[01 · 制作你的第一个预设](../zh/archive/01-制作你的第一个预设.md)**。
> 本目录 01–04 是**格式手册**：查字段、查规则、查排错。

---

## 1. 目录

```
D:\demo\root\hello\
├── meta.json
├── variables.json
├── opening.txt
├── lorebooks\rules.meta.json
├── scripts\panel.meta.json
├── scripts\panel.js
├── styles\panel.meta.json
└── styles\panel.css
```

## 2. 五个最小文件

`meta.json`

```json
{
  "id": "hello",
  "name": "你好预设",
  "variables": "$file$variables.json",
  "opening": "$file$opening.txt"
}
```

`variables.json` → `{ "mood": "平静", "day": 1 }`
`opening.txt` → `墙上的钟停了，只有你听见它在走。`

`lorebooks\rules.meta.json`

```json
{ "name": "规则", "code": "rules", "type": "plaintext", "match": "always",
  "expression": { "last": false }, "content": "你是一个安静的旁白，只用一句话描述画面。",
  "priority": 100, "layer": 99, "role": "system", "disabled": false }
```

`scripts\panel.meta.json` + `panel.js`

```json
{ "name": "角标", "code": "hello", "content": "$file$panel.js",
  "priority": 100, "type": "module", "disabled": false }
```

```js
const el = document.createElement('div');
el.id = 'hello-badge';
document.body.appendChild(el);
const render = () => {
  const v = window.__messageData?.variables ?? {};
  el.textContent = `第 ${v.day ?? '?'} 天 · ${v.mood ?? '未知'}`;
};
render();
window.addEventListener('message', (e) => { if (e.data?.type === 'variables') render(); });
```

`styles\panel.meta.json` + `panel.css`

```json
{ "name": "角标", "code": "hello", "content": "$file$panel.css",
  "priority": 100, "type": "text/css", "disabled": false }
```

```css
#hello-badge { position: fixed; right: 12px; bottom: 12px; padding: 6px 10px;
  border-radius: 6px; background: #111c; color: #fff; font-size: 12px; pointer-events: none; }
```

## 3. 打包导入

```powershell
cd D:\demo
tar -a -c -f demo.zip root
tar -tf demo.zip | Select-Object -First 3     # 必须是 root/...
```

应用 → 预设 → 导入 → 勾选 → 进故事（先配好默认模型）。

## 4. 三条铁律

1. zip 里必须 `root/` 开头、正斜杠（别用 `Compress-Archive`）；
2. 条目目录名精确：`lorebooks` `macros` `regexes` `scripts` `styles` `tools`；
3. `$file$` 后面就是文件名，同目录、同名、ASCII。

## 5. 出问题先看这里

| 现象 | 先查 |
| --- | --- |
| 导入列表为空 | zip 里有没有 `root/` 前缀、是不是反斜杠路径 |
| 没有条目 | 条目目录名拼错；文件不是 `.meta.json` 结尾 |
| 内容为空 | `$file$` 名字与真实文件是否**完全一致** |
| 开场白/变量空 | `meta.json` 里有没有 `"opening"` / `"variables"` 引用 |
| 界面没出现 | 脚本/样式目录名；浏览器控制台里 iframe 的报错 |

更细的排查：[02-手写存档指南](./02-手写存档指南.md)；字段含义：[01-存档结构](./01-存档结构.md)。
