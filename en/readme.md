## What is Secyud Tavern

Secyud Tavern is a highly customizable AI character interaction platform. It allows you to build your own AI interaction workflow.

## Installation

Please choose the appropriate installation guide for your platform:

* [Windows](install/windows.md)
* [Linux](install/linux.md)

## Quick Start

The presets are already included in the documentation and can be obtained from `templates/presets` in the docs.
Import a preset on the preset page, select the imported preset, and click "Enter from preset" to start playing.
