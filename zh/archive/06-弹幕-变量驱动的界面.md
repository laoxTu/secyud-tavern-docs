# 06 · 弹幕：变量驱动的界面（与"一次性效果"的正确姿势）

> **对应预设**：`docs/templates/root/弹幕/`（id `bullet`，3 个条目）｜**前置**：[05](./05-默认交互-渲染层.md)｜**难度**：★★
> **你将得到**：一个跟着故事滚动的弹幕层，并掌握"一次性效果（闪光/音效）也能在翻页时重播"的写法。

---

## 一、引言

弹幕本身很好玩，但这个预设真正的价值是它演示了一条**通用架构**：

> 工具调用是**事件**（只发生一次）；变量是**状态**（一直存着）；界面渲染的是**某一章的状态快照**。

所以"显示效果、声音效果"这类一次性效果，**不能只在工具里播一次**——用户一旦往回翻到那一章，
工具早就调用完了。正确做法是让工具把"这一章要播什么"写进变量，界面每次渲染这一章时重放。

弹幕只有 3 个条目、70 行脚本，却是这套机制最干净的样本。

## 三、理论

### 3.1 三个快照，分别是什么

| 东西 | 归属 | 写入方式 | 翻页时 |
| --- | --- | --- | --- |
| `history.variables` | 整章（并向后继承） | 变量工具 `set_variable` / 变量面板 | 读该章的快照 |
| `history.spaces[i].properties` | **这一轮输出** | 变量工具 `set_temp` | 读该轮的快照 |
| `output.content` | 正文文本 | 模型生成 | 转换后渲染 |

推给 iframe 的 `variables` 消息 =

```js
{ ...variables(history), space: space(history)?.properties ?? {} }
```

也就是"**当前查看的那一章 + 当前那一轮**"。弹幕读的就是 `variables.space.bullets`。

### 3.2 为什么翻页会重放

不是"框架帮你重播"，而是三件事凑在一起：

1. 翻页/翻消息会走 `setIndex → setOutput → prepare`，`PageControl` 重新调用 `renderers.content({realm, history})`；
2. 那次渲染会重新 `postMessage('variables', {...})`；
3. `useMessageData` 收到后 `setMessage({...})` —— **新对象引用**，所以 `useEffect` 依赖它就会再跑。

于是：**离开再回来 = 重播一遍**，而不是"当初播过的残留"。

### 3.3 一次性效果要写成数据

```json
{
  "effects": [
    { "id": "c12-door-slam", "kind": "sound", "src": "slam", "volume": 0.6 },
    { "id": "c12-flash", "kind": "flash", "color": "#ff4444", "duration": 300 }
  ]
}
```

> 📦 **备注 · 为什么效果要带 `id`**
>
> 翻页、生成、重连都会连续推好几条消息；没有 `id` 就没法判断"这一条效果在这一章里播过没有"。
> 建议 `章序号-用途`，例如 `c12-flash`。
> "已播"集合只在本章内有效（离开再回来要重播）；想"整场只播一次"就用 `sessionStorage` 记 `id`。

### 3.4 `set_temp` 还是 `set_variable`

| | `set_temp` | `set_variable` |
| --- | --- | --- |
| 写到哪 | 本章 `space.properties` | 故事变量 |
| 翻回这章 | 还在 | 还在（变量被继承） |
| 翻到别的章 | 没有 | 还在（一直往后带） |
| 适合 | 一次性效果、这一屏的临时状态 | 血量、好感、装备等长期状态 |

弹幕用 `set_temp`：每章的弹幕属于那一章，不该滚到下一章去。

> 📦 **备注 · 弹幕的数据契约**（写在世界书里，等于给模型看的"接口文档"）
>
> ```ts
> // 路径 /bullets
> { [组名: string]: { [昵称: string]: 弹幕文本 } }
> ```
>
> 约定越具体模型越听话：**每组 ≥5 条**、第一层按段落分组、角色的想法也要以弹幕形式发出、
> 观众要对想法有反馈。"弹幕处于异次元，主角不会察觉"这种世界观约束也要写进去。

## 四、实践

### 步骤 1：跑通模板

导入 `settings` + `ui_default` + `弹幕`（`弹幕/meta.json` 里已经写了这两个依赖）。
进故事说一句话，应看到顶部 1/3 区域滚过一条弹幕带。

> 面板一片空白？三种可能：① 没装 `settings`（没有 `set_temp` 可写）；② 没装 `ui_default`（没有 `sUtils`）；
> ③ 模型这一轮没听话写 `/bullets`。先看变量面板里有没有 `space.bullets`。

### 步骤 2：读懂那 70 行

`scripts/panel.script.js` 干了三件小事：

```js
const [variables] = useMessageData('variables');
const groups = Object.values(variables?.space?.bullets ?? {});
```

```js
// 伪随机：昵称决定颜色，内容决定左偏移（看起来不像复制粘贴）
const ink = INKS[(name.codePointAt(0) ?? 0) % INKS.length];
const pos = ((value.codePointAt(0) ?? 0) % 10) + 1;
```

```js
// 动画周期按条数自适应：每条约 1.8s，最少 10s
--cycle = Math.max(10, 总条数 * 1.8)s
```

`styles/panel.style.css` 负责"不挡正文"（只占顶部 `33.33vh`、`pointer-events: none`）和
无缝循环（`width: max-content` + `translateX(100vw → -100%)`）。

### 步骤 3：加一条一次性效果

在 `panel.script.js` 顶部加：

```js
const played = new Set();

function playSound(src, volume = 0.5) {
  try { new Audio(src).volume = volume; } catch {}
}

function flash(color, duration = 300) {
  const layer = document.createElement('div');
  layer.className = 'flash-layer';
  layer.style.background = color;
  document.body.appendChild(layer);
  setTimeout(() => layer.remove(), duration);
}
```

在 `App()` 里处理效果（注意依赖 `variables`，让翻页时重跑）：

```js
useEffect(() => {
  for (const fx of variables?.space?.effects ?? []) {
    if (played.has(fx.id)) continue;
    played.add(fx.id);
    if (fx.kind === 'sound') playSound(fx.src, fx.volume);
    if (fx.kind === 'flash') flash(fx.color, fx.duration);
  }
}, [variables]);
```

样式加一段：

```css
.flash-layer {
  position: fixed;
  inset: 0;
  z-index: 99;
  pointer-events: none;
  animation: fade-out 0.3s ease-out forwards;
}
@keyframes fade-out { from { opacity: .6; } to { opacity: 0; } }
```

### 步骤 4：让模型会写效果

在 `lorebooks/bullet.content.md` 里补一段"效果约定"：

```markdown
当场景出现强刺激（爆炸、门被撞开、突然的黑暗）时，除弹幕外还要用 set_temp 写 /effects：
格式：[{ "id": "c<章号>-<用途>", "kind": "flash", "color": "#ff4444", "duration": 300 }]
id 必须唯一且稳定；kind 只能是 flash 或 sound。
```

### 步骤 5：验收重放

1. 生成一章带 `effects` 的内容 → 看到闪光；
2. **翻到上一章，再翻回来** → 闪光**再播一次**（这就是和"只播一次"的区别）；
3. 同一轮里刷新/重连（若有）→ 不会连播三遍（`played` 去重生效）。

❌ 音效没响：浏览器拦截了自动播放（用户首次交互前），这是平台限制，不是 bug。

## 五、自检与下一步

| 现象 | 原因 |
| --- | --- |
| 面板空白 | 缺 `settings`（无 `set_temp`）或 `ui_default`（无 `sUtils`）；或模型没写 `space.bullets` |
| 弹幕一直重复同一段 | `useMessageData` 收到的是同一份数据、但你在别处重复 `render` 了 |
| 效果播了三四遍 | 没有 `id` 去重；或把 `useEffect` 依赖写成了 `[]`（首帧一次）之后又手动调 |
| 翻页不重播 | 效果存在故事变量里而不是 `space.properties`，或组件没有依赖 `variables` |
| 弹幕挡住正文 | 忘了 `pointer-events: none` / 高度没收住 |
