# 05 · 默认交互：手搭一套渲染层

> **对应预设**：`docs/templates/root/默认交互/`（id `ui_default`，6 个条目）｜**前置**：[01](./01-制作你的第一个预设.md)｜**难度**：★★★
> **你将得到**：一个能自己渲染消息正文的界面层（带组件库），外加一个离线预览页。

---

## 一、引言

互动页面不是 React 应用，而是**一个 iframe**。预设的脚本被注入到这个 iframe 里，
所以"界面长什么样"完全由预设决定——`默认交互` 就是这套机制的最小工程实现：

```
preact（importmap）→ 组件库（sUtils / sComponents）→ 主渲染器（App）
```

它只做一件事：把主应用推来的 `content`（用户输入 + 每轮的思考/工具调用/正文）渲染成页面。
`弹幕`、`模拟经营` 都是在这套地基上加自己的面板。

---

## 三、理论

### 3.1 注入模型

`scripts` 里的条目会被逐个插进 iframe 的 `document`：

```
priority 升序 → 同 code 只注入一次（DOM id = sct-<code>）
importmap 类型特殊：合并成一张表，**最先**注入（否则裸导入解析不了）
整批注入只做一次（window.__injectedScriptInitialized 标记）
```

`styles` 同理（`stl-<code>`），`type === "link"` 时插入 `<link>`，否则 `<style>` 内联。

> 📦 **备注 · `script` / `style` 数据结构**
>
> ```jsonc
> // scripts/xxx.meta.json
> { "code": "script", "content": "$file$script.script-min.js",
>   "priority": 100, "type": "module", "disabled": false, "name": "script" }
>
> // styles/xxx.meta.json
> { "code": "ui", "content": "$file$ui.style-min.css",
>   "priority": 100, "type": "", "disabled": false, "name": "样式" }
> ```
>
> `type` 是"原样塞给 DOM 的 type 属性"：`module` 当 ES module 执行、`importmap` 合并、
> `link` 当外链 URL；样式写 `""` 也等同内联 `<style>`（模板里就是这么写的）。

### 3.2 三层：库、工具、应用

| 条目 | `code` | 作用 |
| --- | --- | --- |
| `preact.meta.json` | `preact` | `type: "importmap"`，把 `preact` / `preact/` / `@preact/signals` 映到 esm.sh |
| `components.meta.json` | `components` | 定义 `window.sUtils` 与 `window.sComponents`（组件库本体） |
| `script.meta.json` | `script` | 主渲染器：`renderComponent(App, 'app')` |

顺序靠 `priority`：`preact`/`components` 是 `0`，主渲染器是 `100`。**改顺序 = 必崩**（裸导入找不到 `preact`）。

### 3.3 数据通道

iframe 里能拿到三种东西：

| 通道 | 内容 | 怎么用 |
| --- | --- | --- |
| `window.__messageData.content` | `{ prompt, spaces: [{ output, thought, callings }] }` | 主渲染器的原料 |
| `window.__messageData.variables` | 当前章的变量 + `space`（本轮 `set_temp` 写的东西） | 状态面板、弹幕 |
| `window.addEventListener('message')` | 每次推送后一条 `{ type }` 消息 | 触发重渲染 |

`useMessageData(type)` 就是"读初值 + 订阅"的封装：内部 `useState` + `message` 监听，
每次推送都 `setMessage({...})`——**新对象引用**，所以下游 `useEffect` 会重跑。

> 📦 **备注 · `sUtils` / `sComponents`**
>
> | API | 作用 |
> | --- | --- |
> | `get(obj, 'a.b.c', 默认值)` | 安全取深层字段 |
> | `useMessageData(type='content')` | `[message, setMessage]`，订阅指定通道 |
> | `renderComponent(Component, id)` | 创建 `<div id=id>` 挂到 body 并渲染（**每次调用都会新建一个 div**） |
> | `appendItemInput(item)` | 把 `[名称]` 插到主应用输入框的光标处 |
> | `weightRandom(items, weightOf)` | 按权重随机取一项 |
>
> `sComponents`：`SFloating`（悬浮球+面板）、`STab`（页签）、`SRadarChart`（雷达图）、
> `SExpand`（折叠）、`SVariableImage`（按变量名取图）。

### 3.4 主渲染器的结构

`script.script.js` 只做一件事：把 `content` 铺开。

```js
function App() {
  const [message] = useMessageData();       // 默认就是 'content'
  return h('div', { className: 'container' },
    ht(message.prompt, { className: 'prompt' }),          // 玩家输入
    message.spaces?.map((s) => h(space, s)));             // 每轮：思考/工具/正文
}
renderComponent(App, 'app');
```

`space()` 里把 `thought` 和 `callings` 做成可折叠块，`output` 直接渲染成 HTML。
配套的 `lorebooks/rules`（`layer: 89`，`role: system`）只干一件事：告诉模型"允许输出 HTML 标签"。
**渲染层的存在，要求提示词配合**——这是很容易忽略的一环。

## 四、实践

### 步骤 1：先用模板跑通

导入 `默认交互`（连同它依赖的 `settings`），进故事，确认正文是"有样式的 HTML"。
再打开 `workspace/默认交互.html`（先 `python -m http.server 8080` 起个静态服务）——
这是**离线预览页**：手塞一段 `window.__messageData`，按运行时顺序引样式与脚本，
不用开应用就能调界面。

> 预览页里那个 `component.style.css` 少个 `s`（实际是 `components.style.css`），会 404，改一下即可。

### 步骤 2：写一个自己的渲染层

在 `D:\demo\root\my_ui\` 下建四个条目。先建目录：

```powershell
mkdir D:\demo\root\my_ui\scripts
mkdir D:\demo\root\my_ui\styles
mkdir D:\demo\root\my_ui\lorebooks
```

`my_ui/meta.json`：

```json
{ "id": "my_ui", "name": "我的界面", "version": "1.0.0", "requires": [] }
```

**① importmap**：`scripts/depts.meta.json`

```json
{ "name": "preact 导入", "code": "preact_map", "content": "$file$deps.json",
  "priority": 0, "type": "importmap", "disabled": false }
```

`scripts/deps.json`：

```json
{
  "imports": {
    "preact": "https://esm.sh/preact@10.23.1",
    "preact/": "https://esm.sh/preact@10.23.1/"
  }
}
```

**② 应用**：`scripts/app.meta.json`

```json
{ "name": "渲染器", "code": "app", "content": "$file$app.js",
  "priority": 100, "type": "module", "disabled": false }
```

`scripts/app.js`：

```js
import { h, render } from 'preact';
import { useEffect, useState } from 'preact/hooks';

function useChannel(type) {
  const [data, setData] = useState(window.__messageData?.[type] ?? {});
  useEffect(() => {
    const onMessage = (e) => {
      if (e.data?.type === type) setData({ ...(window.__messageData?.[type] ?? {}) });
    };
    window.addEventListener('message', onMessage);
    return () => window.removeEventListener('message', onMessage);
  }, [type]);
  return data;
}

function App() {
  const content = useChannel('content');
  return h('div', { className: 'my-body' },
    h('div', { className: 'my-input' }, content.prompt ?? ''),
    (content.spaces ?? []).map((s) =>
      h('div', { className: 'my-turn', dangerouslySetInnerHTML: { __html: s.output ?? '' } })));
}

const root = document.createElement('div');
root.id = 'my-app';
document.body.appendChild(root);
render(h(App), root);
```

**③ 样式**：`styles/app.meta.json`

```json
{ "name": "样式", "code": "app_style", "content": "$file$app.css",
  "priority": 100, "type": "", "disabled": false }
```

`styles/app.css`：

```css
.my-body { padding: 16px; line-height: 1.7; }
.my-input { opacity: .7; border-left: 3px solid #888; padding-left: 8px; margin-bottom: 12px; }
.my-turn { margin-bottom: 12px; }
```

**④ 提示词配合**：`lorebooks/html.meta.json`

```json
{ "name": "正文格式", "code": "html", "type": "plaintext", "match": "always",
  "expression": { "last": false },
  "content": "输出以文字为主；需要标题、列表等特殊格式时，使用 HTML 标签，但不要每句都包标签。",
  "priority": 100, "layer": 89, "role": "system", "disabled": false }
```

### 步骤 3：验收

```powershell
cd D:\demo
tar -a -c -f demo.zip root
```

导入后进故事：

- ✅ 正文被包在 `.my-body` 里，输入框内容有左侧竖线；
- ✅ 每轮正文都会追加一块（`spaces` 是数组）；
- ❌ 如果控制台报 `Failed to resolve module specifier "preact"` → importmap 没生效（检查 `type: "importmap"` 与 `priority: 0`）；
- ❌ 如果页面出现两份内容 → 你调了两次 `render`（或复制了模板的 `script` 条目）。

### 步骤 4：搭自己的组件库（可选）

把常用 UI 挂到 `window` 上，后面的预设就能直接复用：

```js
window.myUI = {
  card: (title, body) => h('div', { className: 'my-card' }, h('b', {}, title), body),
};
```

然后在另一个预设的脚本里 `const { card } = window.myUI;` —— 这就是 `默认交互` 提供 `sUtils` 的思路。

## 五、自检与下一步

| 现象 | 原因 |
| --- | --- |
| `Failed to resolve module specifier` | importmap 条目缺失 / 顺序不对（必须最先） |
| 脚本没执行 | `type` 不是 `module` 却用了 `import`；或 `code` 与别的预设撞车被去重 |
| 渲染两份 | `renderComponent` 每次调用都会新建 div；多次注入同 `code` 不会重复，但重复 `render` 会 |
| 样式不生效 | 样式条目 `type` 写成了 `link` 但 `content` 不是 URL；或 `code` 撞车被去重 |
| 正文是一坨纯文本 | 没有提示词约定输出 HTML；`output` 里的换行不会自动变 `<br>` |
