# 预设教程集

这组教程带你把 `docs/templates/root/` 里的 **8 个预设**逐个做一遍——不是读一遍，是**动手复刻**。
每篇都是同一套结构：**引言 → 教学目的 → 理论 → 实践 → 自检**，数据结构用 `📦 备注` 穿插在正文里。

> 格式参考手册（字段表、导入导出规则、排错）在 [`../../archive/`](../../archive/readme.md)；
> 想快速做出第一个预设，也可以先看那里的 [00-快速上手](../../archive/00-快速上手.md)。

## 二、读之前的环境准备

1. **应用跑起来**：`pnpm dev`（默认 `127.0.0.1:12804`）或 `pnpm start`。
2. **配一个默认模型**：没有默认模型时"从预设开始"会被拦。
3. **能打包**：Windows 上确保 `tar` 可用（Win10+ 自带）。**不要用 `Compress-Archive`**，它写出的反斜杠路径会让导入静默失败。
4. **准备一个工作目录**，例如 `D:\demo\root\`，每篇教程都从这里改、打包、导入。

```powershell
cd D:\demo
tar -a -c -f demo.zip root     # 打包
tar -tf demo.zip               # 必须有 root/... 前缀
```

> 模板里的预设不用你自己敲：`docs/templates/root/` 已经是解开的存档树。
> **学习建议**：先原样导入一遍模板（能跑），再对着源码改一处、重打包、看变化——比从零抄一遍快得多。

## 三、四个通用概念（后面不再重复）

| 概念         | 一句话                                            | 备注                                                                                      |
| ------------ | ------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **存档**     | 一个 zip，所有文件都在 `root/` 下面               | zip 是产物，`docs/.gitignore` 忽略；模板用 `build.bat` 现场生成                           |
| **预设**     | `root/<目录>/meta.json`，`id` + `name` 必填       | 目录名随意，`id` 才是身份；同 `id` 再导入 = 覆盖                                          |
| **条目**     | 六个固定目录里的 `*.meta.json`，一个文件一条      | `lorebooks` `macros` `regexes` `scripts` `styles` `tools`，一个字母都不能改               |
| **`$file$`** | 字段值写 `"$file$文件名"`，内容放同目录的独立文件 | 只对 `content`/`value`/`variables`/`opening`/工具的 `config.*` 生效；名字必须**完全一致** |

三条铁律（每篇结尾都会再提一次）：

1. zip 里必须 `root/` 开头、正斜杠；
2. 六个条目目录名精确；
3. `$file$` 后面就是文件名，同目录、同名、**ASCII**。

## 四、每一篇的用法

- **引言**：这个预设为什么存在、解决什么痛点——先判断"我要不要学"。
- **教学目的**：这一篇结束时你应会什么，可以当验收清单。
- **理论**：机制怎么跑（带源码位置），这段**值得慢读**，后面改东西全靠它。
- **实践**：手把手的步骤，每步有"✅ 应该看到"。
- **自检**：做错了怎么查；以及"接着往下学什么"。

`📦 备注 · 数据结构` 是插入式说明，第一次读可以跳过，动手时回来查。
