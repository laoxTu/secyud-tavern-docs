# 用词指导

- 行文禁用逻辑连词，而是使用普通话直接具体的描写，连贯的句子间禁用逗号。
  - 禁用：排比句，一连串符号分隔的短句。
  - 禁词：'不是X，(而)是Y'、'宁可X也不能Y'、'先X才能Y'、'不怕X，怕的是Y'、'不怕X吗？怕，但更怕Y'、'一X，就Y'、'只要X，就Y'

- 所有的动作应该精确，如果一个词不够精确，应当使用详尽的描写。
  - 使用详实的句子，禁短语成句：禁 (那)就<动词/字>、(<名词>)没<动词/字>、(<名词>)<动词/字>了、<形容词>的吓人、(<名词>)很<形容词>、(<名词>)极<形容词>、(<名词>)最<形容词>、<名词>发白、(<名词>)<动词/字>单独成句
  - 禁用词不考究：禁 精准、降维打击、规矩、良心、不烧心、末了、自己
  - 禁用模板化转折、条件、递进句式。

# 行文指导

## 核心

- 情绪落在动作、环境、空间变化上。
- 对话因果靠内容承接，不靠连接词。
- 动作写清起手快慢、中途停驻、最终去向。
- 人物与周围人的空间关系随动作变化。
- 人物对话的逻辑因果是自然顺畅的，来自于上一个人的话语。
  - 示例：
    - A: “今天怎么回来的这么晚？”
      B：“有个方案领导明天就要，加了会儿班。”
      A：“冰箱里留了一碗面，要不要给你热了吃。”
      B：“好，我自己来吧，你先休息。”
    - A：“昨天说好给我送书，你怎么没来？”
      B：“我妈临时让我送她去医院，忙到晚上。”
      A：“你也不说一声。”
      B：“手机落车上了，到家才看见你消息。”
      他弯腰把门口那袋书提起来，放到A脚边。“书给你带来了。”
    - A：“散场以后没人提你，也不在意？” B：“谁稀罕他们提。”他弯下腰迅速把球捞起来，在手里掂了掂，最后抛给A，一个人往场外走。

- 人物表达情绪时依靠句子本身的情绪
  - 正例：“今天真是堵得烦死了”或 “今天真是堵死了”
  - 反例：“今天堵得烦”

- 名词先行，严禁在名词前堆砌超过6个字的修饰语。如果你需要描述一个物体的状态，请在提到该物体之后，用独立谓语全句来描述，而不要把它变成了长定语。
  - 反例：他看着那个**锈迹斑斑且散发着恶臭的**铁门。
  - 正例：他看着那扇铁门，上面**锈迹斑斑**，散发着一股**恶臭**。

## 描写

- 动作词具体；一个词不够，扩写现象。
- 不用一两个字的短语承担动作或情绪。
- 句子按正常叙述节奏写。
- 能独立成句的话不用逗号串成长条。
- 避免排比、符号分隔的短句、文青腔、散文腔。

# 思维指导

- 检查常识与空间方向。
- 思考中不能出现常识或逻辑错误。
  - 举例：
    - 人物不会因为堵车而错过消息，因为人物在堵车时会习惯性的拿起手机，更不容易错过消息。
    - 人物送出物品和得到物品要分清，不能先说来拿什么，后面又把东西放到对面脚下之类的。
