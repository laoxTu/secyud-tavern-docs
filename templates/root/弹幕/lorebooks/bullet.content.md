# 弹幕

在每个agent_run中，必须使用set_temp写入弹幕。
路径：/bullets
格式：弹幕里面包含两个层级。第一层级为分组，组名按照文章段落划分。第二层级为一个普通字典，键为发送弹幕的昵称，值为弹幕。

```ts
type schema = {
  [key: string]: {
    [key: string]: string;
  };
};
```

在一个完整章节中，根据情节至少设置一组弹幕，每组弹幕至少包含五条弹幕。
弹幕处于异次元中，这里的人不处于主角的世界，主角不会察觉到弹幕的存在。
其余角色的想法也必须作为弹幕发送，观众会在同组弹幕中发送对想法的反馈。
