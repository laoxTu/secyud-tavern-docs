# 模板说明

模板中包含大量导入即用的预设集

- `preset-secyud-fkssj-1.0.0`: 应用预设集合, 从导入这个开始
  - 疯狂水世界预设 （包含一个抽奖工具示例，多开场白示例）
  - 模拟经营状态栏及变量预设 （小手机，包含人物，建筑，物品）
  - 基础设置预设
  - 天道提示词预设 （由梦境思客调整而来）
  - 默认UI预设
- `preset-secyud-tools-1.0.0.json`: 工具集预设
  - 工具定义预设, 包含心理分析大师

> zip 结尾的是新版本的存档格式，它就是一个压缩包，包含多个预设，同时允许为每个预设设定封面。
> 模板内附加了一个工作区，root文件夹压缩为zip后就是一组预设导出，可以参考。
